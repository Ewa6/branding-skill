# Final delivery and truthful completion

Create a portable, curated package inside the project output directory, with [delivery notes](../assets/delivery.md), [asset register](../assets/asset-register.csv) and [QA](../assets/qa.md). Keep history elsewhere.

## Expected results

For a full brand scope, include:
- Strategy/brief with audience, positioning, promise and key messages.
- A usable logo master and relevant SVG/transparent PNG variants plus usage.
- Standalone tone-of-voice guide with concrete examples and vocabulary.
- Brand book HTML and visually reviewed PDF.
- Canonical tokens, palette/contrast guidance and type specifications.
- Required icons, picture library and signature component sources/specimens.
- Representative final applications, editable source and exports.
- Relevant print rules/PDFs/calibration.
- Sources, licences, approval/status inventory and QA findings.

Omit inapplicable extras; don't treat a picture library or print pack as mandatory for a service brand that needs neither. Do not add business cards, social campaigns, packaging, domain registration or production website work without scope.

## Final pass

1. Reconcile current decisions and references. Remove obsolete prompts and rejected designs from the production package.
2. Verify assets are real separate outputs: SVG vector fidelity, PNG alpha, local fonts, PDFs, editable sources and working relative links.
3. Inspect actual book/application renders. Test intended viewport/print sizes and realistic content.
4. Check the inventory for status, source, licence and intended use. Keep unapproved refinements clearly separate from approved standards.
5. Inspect public contents and metadata for private data, paths/secrets or unlicensed references.
6. Build a ZIP from an explicit file/folder allowlist, excluding history, private files, caches, dependencies and unrelated repository contents. Preserve relative paths and licences.
7. Extract into a clean temporary directory and open the entry HTML without relying on the source tree or network. Confirm linked assets and PDFs exist. A shareable ZIP must not depend on local server URLs.
8. Report what is final, working or blocked by an external dependency. Ask only the real remaining choice or authorization.

Do not label a low-resolution reference, an unfaithful tracing, an unreviewed batch or a preparation collage “production-ready”. If a physical print trial is still outstanding, include a concrete test sheet and state the limitation while delivering all completed digital work.

If the owner chose an external design handoff, prepare the same curated package plus a concise current brief, fixed constraints, unresolved choices and exact sources. It is a handoff, not proof the external tool completed anything. NieZamulaj used this exception; other full runs finish within Codex.
