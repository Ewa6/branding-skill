# Lessons to apply without repeating failures

| Observed problem or scaffold risk | Better method |
| --- | --- |
| Old briefs and prompts resurrected superseded decisions | Keep a current decision index and exclude rejected visuals from the delivery bundle |
| “No health promises” became “never mention the audience” | Record exact scope; do not silently tighten the owner's rule |
| An AI recommendation was treated as a user choice | Track source and approval scope per component |
| A team-labelled calm variant felt chaotic to the owner | Owner feedback wins; compare actual density and competing focal points |
| A new logo interpretation replaced the preferred reference | Preserve the exact reference; compare fidelity before producing variants |
| Generated serif appearance was called an identified font | Compare actual licensed fonts, genuine italic, glyphs and optical size |
| Pretty blank boards concealed crowded finished states | Test empty, partial and full states with realistic long content |
| Sticker dimensions were guessed from illustration style | Ask or recover actual stock dimensions before committing geometry |
| Numbers floated away from fields; arrows and a footer added noise | Test number association and reading order; remove redundant cues |
| Physical fit was solved but the result looked like a Word document | Preserve personality through hierarchy, picture allocation and reward emphasis; fit alone is insufficient |
| Repeated “done” copy and mini decorations overwhelmed full boards | Reduce redundancy, keep optional accents subordinate and compare plain states |
| Picture swaps were mistaken for thematic board accents | Treat pictures, utility icons, decorative stickers and board-level themes as distinct layers |
| A fixed library target can encourage premature mass generation | Approve a representative family, then expand only the useful subjects |
| A quiet-state message implied unimplemented offline safety | Verify product behavior before promising saved data or synchronization |
| A raster sheet was presented as reusable component assets | Create individual sources/exports and a manifest; test transparency |
| Domain nonresponse or duplicate lookups were called “free” | Record actual evidence and distinguish no record from purchasable availability |
| A preparation ZIP was presented as a final brand system | Separate proposals, approved standards and external production blockers |
| A rigid gate after every task interrupted progress | Ask at real owner decisions; complete routine authorized production autonomously |

These methods come from the case study. The rejected arrows, plate motifs, circular targets and substitute logos are not recommended default options for other projects. Nor is their rejection a universal design ban: recover the reason and apply it to the new context.
