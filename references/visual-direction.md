# Visual direction through controlled comparisons

Read current brief, voice, decisions and owner references. If an identity is already chosen, refine it unless the agreed rebranding scope authorizes replacement. For rebranding, use the current identity as a comparison baseline and hold retained components fixed; explore only the changes justified by the brief.

Write a short art-direction paragraph: composition, palette roles, typography character, shapes, image treatment, material and spacing. Include project exclusions only. Use [the prompt template](../assets/mood-board-prompt.md) for raster studies where useful.

## Compare fairly

Usually two or three genuinely different directions are enough. Choose axes relevant to the owner's question: calm versus expressive, picture-led versus type-led, editorial versus tactile. A/B/C are study identifiers, not fixed aesthetic recipes.

Use the same product text, signature component, palette sample, picture subjects and intended-use fragments. Show the logo reference unchanged if fixed. Where needed, show phone, print or real-context use. Include B&W for the actual print requirement; it can be tested in later functional specimens rather than multiplying every moodboard.

Compose exact copy and actual type in HTML/SVG when precision matters. Use image generation for visual exploration and artwork; generated text, lighting, hex colours and glyphs are not production specifications.

## Read component-level feedback

The owner may pick type from one board, images and spacing from another. Record each component and make a coherent synthesis within that request. Do not call a whole board approved or invent an unrequested hybrid.

Extract selected elements into individual studies: stickers/shapes, picture family, font comparisons. Keep decorative stickers separate from physical label stock. A round completion badge does not imply the printer label must be circular.

Before showing, inspect composition, legibility, source-logo fidelity, unwanted associations and privacy. Fix obvious defects before asking the owner to judge taste. Preserve alternatives as history with their actual status.
